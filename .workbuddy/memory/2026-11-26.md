2. 编译层作为独立层插入知识面与整理面之间，不替换现有层。
3. P0 只建表与口径，先补 L2 向量 + L3 实体/事实；编译器 P1 开工（不把编译层建在空底座上）。
4. I16–I20 新不变量：evidence 必需、stub 不丢弃、沉淀不自动 active、同一 embedding 模型/维度、wiki 不替代 source。
