## 0. 使用说明

- **正式名**：文档与代码中必须使用的写法。
- **不推荐**：口语或旧文档中的说法，出现时应替换。
- **出处**：最早定义该术语的文档章节。

## 2. 记忆相关

### 2.1 记忆类型（语义维度）

| 代码 | 名称 | 半衰期 | 说明 |
|---|---|---|---|
| F | fact | ∞ | 事实，不衰减 |
| P | preference | 90 天 | 偏好，压缩为常量注入 |
| J | judgment | 180 天 | 判断，允许随时间演化 |
| C | commitment | 到期 +30 天 | 承诺，必须有截止时间 |
| R | relation | 365 天 | 人与组织/项目的关系 |
| E | event | ∞ | 发生过的事，不可覆盖 |

> 类型决定生命周期与冲突规则（05 §1.4）。

### 2.2 注入层（位置维度）

| 层 | 名称 | 配额 | 说明 |
|---|---|---|---|
| L1 | 常驻层 | ≤500 tokens | 事实、承诺、高置信判断 |
| L2 | 检索层 | ≤300 tokens | 按话题检索的摘要与判断 |
| L3 | 常量层 | ≤100 tokens | 压缩后的偏好 |

> 层只决定「放哪、放多少」，不决定「是什么」（00 §3 主张二）。

### 2.3 其他字段

| 术语 | 取值 | 说明 |
|---|---|---|
| 来源（origin） | `user_confirmed` / `user_explicit` / `system_inferred` | 可信度来源；推断不得直接 active（I10） |
| 保真度（fidelity） | `pending` / `pass` / `minor_deviation` / `severe_distortion` / `not_applicable` | 决定能否注入（05 §5） |
| 状态（status） | `proposed` / `active` / `corrected` / `superseded` / `forgotten` | 生命周期（04 §4.1） |
| 有效区间 | `valid_from` / `valid_to` | 判断在用户认知中成立的时间 |
| 记录区间 | `tx_from` / `tx_to` | 系统记录/修正该版本的时间 |

## 8. 易混淆对照

| 容易混淆 | 区别 | 一句话记忆 |
|---|---|---|
| 事件 vs 记忆 | 事件是「发生过什么」，记忆是「关于你的结论」 | 事件是原料，记忆是成品 |
| 修正 vs 覆盖 | 修正生成新版本并关闭旧版本；覆盖会丢失历史 | 修正只增，覆盖会丢 |
| 遗忘 vs 删除 | 遗忘有级联、墓碑、回执；删除只是少了一行 | 遗忘要能证明 |
| 张力 vs 冲突 | 张力是系统中的一条记录，冲突是语义上的对立关系 | 张力是冲突的载体 |
| 投影 vs 视图 | 投影是数据层结果，视图是用户看到的分组 | 投影落库，视图呈现 |
| 层 vs 类型 | 层管注入位置，类型管生命周期 | 层是放哪，类型是什么 |
| 快照 vs 版本 | 快照是某一时刻的整体认知，版本是单条的修订历史 | 快照看全局，版本看一条 |
| `valid_time` vs `tx_time` | 前者是「你何时这么想」，后者是「系统何时记下」 | 一个是认知，一个是记录 |
| 摘要 vs 记忆 | 摘要记录一场对话发生了什么，记忆记录关于你的判断 | 摘要记事，记忆识人 |
| 质询 vs 提醒 | 质询只在对话中、有预算、需反馈；提醒是推送 | 质询对话内，提醒已废弃 |
